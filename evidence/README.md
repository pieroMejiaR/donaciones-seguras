# Evidencia de pruebas

Una carpeta por prueba (`T01/`, `T02/`, …) con capturas o salidas y un `README.md` corto: qué se probó, cómo y qué resultó.

**El repositorio es público.** Antes de subir cualquier archivo, quitar o tapar:

- el ID de la cuenta de AWS y los ARN que lo contienen;
- correos y nombres de usuario de Cognito;
- tokens completos (los JWT se recortan a sus primeros caracteres);
- URLs firmadas, claves y valores de `.env`.
